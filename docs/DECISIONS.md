# 제품·기술 결정 기록

## 2026-11-13: 범위
- 대상: 처음 사무/학습용 키보드를 고르는 한국어 사용자. 고사양 게이밍, 커스텀 빌드, 건강/통증 개선 추천은 제외.
- 가치: 필요한 개념을 짧게 익히고 필수 조건을 걸러, 출처와 제약이 드러난 소수 후보를 비교.
- P0: 입문 설명, 5단계 조건 입력, 필수 조건 필터, 명시적 미확인/빈 결과, 근거와 공식 링크/옵션/날짜, 모바일/접근성.
- P1 (이번 포함): 최대 3개 비교, 구매 체크리스트 다운로드, 브라우저 내 선택 보관과 삭제, 명시적 로컬 피드백 저장/내보내기.
- 제외: 로그인·결제·실시간 가격/재고·자동 쇼핑몰 수집·원격 분석·추천 생성 AI·여러 카테고리·배포.

## 기술
- Vite + ES modules + JSDoc/TypeScript 정적 검사. UI 규모가 작아 프레임워크/라우터/상태관리 패키지 없이 구현한다. 순수 추천 엔진과 데이터/화면/저장을 분리한다.
- Node 22.14, npm lock. 개발 의존성만 Vite, TypeScript, Playwright, axe. 프로덕션 API/런타임 패키지 없음.
- React/Next 등의 대안은 서버/동적 대규모 UI 필요 시 재검토. 현재는 비용·환경·배포 종속성을 낮추는 쪽 선택.
- 브라우저 데이터는 localStorage, 외부 전송/쿠키/통계 SDK 없음. 저장 차단 시 메모리로 계속 진행하고 사용자에게 알림.
- 정적 한국어 콘텐츠와 직접 만든 SVG. 외부 폰트/사진/생성 이미지 비용·의존성 없음. 제품 도식은 실물 사진이 아님을 밝힘.

## 추천 규칙
1. 확인일·공식 URL·필드 출처 감사. 유효기간 90일 초과/미래/오류면 후보 보류.
2. OS, 연결, 숫자패드, 기기 전환을 필수 조건으로 검사. 부적합과 미확인을 구분하고 둘 다 추천에서 제외.
3. iPadOS의 수신기/USB 어댑터 경로는 미확인. 유선/수신기만으로 멀티 기기를 전환할 수 있다고 Bluetooth 능력을 잘못 적용하지 않음.
4. 엄격한 소음 또는 예산 이내 확인을 요구하면 현재 자료로는 적합 후보 0개. 조건을 자동으로 완화하지 않고 사용자에게 수정 선택 제공.
5. 작은 폭(330 mm 이하), 충전식, 낮은 키 중 선택 선호에 부합하면 내부 정렬 가중치 1. 작은 폭 선호일 때 폭 오름차순, 나머지 동률은 고정 ID 순. 점수·만족 확률·시장 순위를 표시하지 않음. 330 mm는 서비스 편집 기준이다.
6. 최대 3개를 먼저 보여주며 전체 일치 후보도 확인 가능. 출처는 추천 이유의 해당 필드와 연결.

## 개인정보/운영
브라우저 조건과 피드백은 사용자 기기에만 남는다. 내보내기를 해야 수동 분석 가능하며 자동 수집이나 실시간 사용 통계가 없다. 다운로드 파일 전달·외부 참여자 모집·배포는 이번에 실행하지 않는다. 저장소 공개는 사용자 승인 받음; GitHub 저장소 공개는 서비스 배포와 별개다.
