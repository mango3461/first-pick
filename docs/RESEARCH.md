# 문제와 초기 조사

조사: 2026-11-12~13 KST. 공개 웹 문서 열람과 제조사 페이지의 구조화 사양 확인. 인터뷰·판매량 분석·설문은 하지 않았다. 아래 선택은 시장 우위가 증명된 결론이 아니라 검증할 제품 가설이다.

## 목적과 약점
처음 접하는 제품의 전문 용어를 자신의 사용 조건으로 바꾸고, 후보를 고른 이유와 아직 모르는 점을 확인하도록 돕는다. ‘좋은 제품 순위’보다 구매 전 판단 능력이 목표다.

핵심 약점은 교육 콘텐츠와 비교 필터가 이미 있다는 것이다. 설명만 생성하는 서비스는 차별성이 약하다. 제품이 실제로 손에 맞는지, 국내 결제 가격·재고가 어떤지는 사양만으로 해결할 수 없다. 작은 카탈로그는 브랜드/모델 편향이 크다. 이를 숨기면 기존 쇼핑몰보다 나쁜 의사결정을 만들 수 있다.

## 카테고리 비교 (판단, 시장 통계 아님)

| 후보 | 확인한 데이터 접근성 | 입문자에게 어려울 것으로 예상하는 점 | 이번 결정 |
|---|---|---|---|
| 키보드 | Logitech/Keychron 공개 사양. 연결·숫자패드·기기 전환을 직접 확인 | 축·키감·소음을 혼동; 충전과 유선 입력 혼동 | 채택: 설명과 명확한 필터를 작은 범위에서 검증 가능 |

| 모니터 | [Dell 공식 목록](https://www.dell.com/ko-kr/shop/all-monitors/sac/monitors/all-monitors)에 해상도·포트·크기 등 공개 | 글자 크기·시청 거리·노트북 출력 규격까지 고려해야 함 | 보류: 첫 세션에서 다룰 조건과 오추천 비용이 더 큼 |

시장 규모, 한국 구매 수요, 경쟁사의 전환율, 사용자 불만의 빈도는 확인하지 않았다. 공개 문서 존재가 수요 증거는 아니다.

## 데이터 타당성 검증

`src/data/catalog.js`에 모델·지역·옵션과 필드별 출처/확인 메모를 기록했다. Logitech K380s, K650, MX Keys S와 Keychron B1 Pro, B6 Pro, V1 Max 총 6개다. 각각의 공식 URL과 확인일은 앱에서도 볼 수 있다.

- 직접 열람한 공식 페이지의 기술 사양·FAQ를 사용했다. Logitech의 접힌 사양은 동일 페이지 HTML의 구조화 데이터도 읽었다. 런타임 크롤러는 없다.
- K650 FAQ에 AAA와 AA가 함께 나타났다. 교체형 건전지라는 일치된 정보만 쓰고 정확한 규격은 미확인으로 남겼다.
- 한국어 모델과 글로벌 ANSI 모델을 섞어 같은 옵션처럼 표시하지 않는다. 글로벌 SKU의 국내 가격·한글 각인·보증·판매 여부는 미확인이다.
- iOS 표기만 있는 모델에 iPadOS 호환을 추론해 넣지 않았다. 제조사가 특정 OS를 명시하지 않은 것은 ‘미확인’이며 ‘작동 불가’와 구별한다.
- 소음은 전 제품 null. 공식 마케팅의 ‘조용함’으로 dB나 도서관 적합성을 만들지 않는다. [CHERRY의 축 분류](https://www.cherry.de/en-gb/products/switches)는 개념 설명에만 사용한다.
- 해외 표시 가격은 관찰 가능하지만 국내 결제 총액과 다르므로 가격 필터 데이터로 쓰지 않는다. 한국 가격을 안정적으로 공급하는 무료 API의 권한/조건을 확보하지 못했다. 무료 API가 전혀 없다는 뜻은 아니다.
- 자동 구매 링크/리뷰 텍스트/사진 복제 없이 원문으로 연결하고 필요한 사실을 간결히 요약한다. 자료 이용 허가 계약을 확보한 것은 아니며 공개 페이지가 무제한 재배포를 허용한다는 가정도 하지 않는다.

## 무료 구현 가능성과 유지

정적 파일 + 직접 확인한 작은 데이터 + 결정론적 규칙으로 운영 API 비용을 없앤다. 서버·GPU·로컬 LLM은 필요 없다. 설명 생성형 AI는 오답 검증과 운영 비용을 늘리므로 제외한다. 6개 사양 수동 검토는 실행 가능성을 확인했지만, 월 유지 시간이나 대규모 카탈로그 유지 가능성은 아직 측정하지 않았다.

사양은 확인일로부터 90일이 지나면 후보에서 제외한다(편집 정책이며 제조사의 변경 보증 기간이 아님). 링크 점검은 상태 코드만 검사하며 재검토 날짜를 갱신하지 않는다. 자동 가격 수집과 실측 평가는 지금 범위에서 제공하지 않는다.

## 제품 가설

가설: 첫 사무·학습용 키보드를 고르는 한국어 사용자는 ‘왜 이 후보인지, 무엇은 아직 모르는지’가 드러나면 더 적은 혼란으로 후보를 좁힐 수 있다. 검증 대상은 실제 구매 유도보다 이해와 선택 근거 설명이다. 실험과 중단 기준은 `VALIDATION.md`에 정의한다.
