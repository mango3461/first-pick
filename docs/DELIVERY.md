# 첫픽 0.1 인수인계 — 2026-11-13 KST

## 처음 목표와 완성 범위
목표는 처음 구매하는 제품 분야의 핵심 개념을 이해하고 자신의 조건에 맞는 제품을 고르도록 돕는 서비스다. 이번에는 공식 정보 접근성과 검증 난도를 비교한 뒤 **사무·학습용 첫 키보드**를 선택했다. 2개 제조사 6개 모델의 공식 사양으로 후보를 좁히는 실제 동작하는 로컬 웹 앱을 완성했다. 전체 제품 시장이나 실시간 쇼핑 비교 서비스는 아니다.

## 결정과 근거
- 전문 용어 설명 → 사용 조건 → 후보/제약/출처 → 비교/체크리스트 흐름. 단순 교육/필터는 경쟁 서비스에도 있어, 설명 가능한 선택과 미확인 사실의 명시를 검증 가설로 잡았다.
- 무료 정적 앱: Vite, JavaScript ES modules, JSDoc/TypeScript 검사. 서버·DB·유료 API·LLM·GPU가 필요 없다.
- 공식 사양은 필드별 근거로 연결하고 옵션·지역·확인일을 구분한다. 90일을 넘긴 자료는 추천에서 제외한다.
- 실시간 가격과 동일 조건 소음 측정 데이터가 없으므로 해당 엄격 조건에는 추천을 보류한다. 사양을 실사용 만족도나 도서관 적합성으로 바꾸지 않는다.
- 자세한 대안/트레이드오프: [RESEARCH](RESEARCH.md), [DECISIONS](DECISIONS.md).

## 기능과 사용
가이드 3개, 5단계 조건 입력, 필수 조건 일치/불일치/미확인 구분, 선호 정렬, 후보 전체 보기, 최대 3개 비교, 출처·옵션·확인일, 체크리스트 다운로드, 로컬 조건 복원·삭제, 선택적 로컬 피드백 저장/내보내기. 가격/소음 검증을 외형으로 흉내 낸 기능은 없다.

프로젝트 폴더에서 `npm ci` 후 `npm run dev`; 기본 `http://127.0.0.1:5173/`. Windows 정책으로 npm.ps1이 막히면 npm.cmd를 사용한다. 설치/실행/예외/기타 환경 설명은 [README](../README.md).

## 확인 사실 / 가정 / 미검증
- 확인: 공식 6개 모델의 공개 문서와 추천에 사용하는 사양, K650 공식 표기 충돌, 동일 조건 재현 가능한 추천 결과, 로컬 저장·파일 생성, 브라우저 동작.
- 가정: 처음 구매하는 한국어 사용자에게 ‘왜 맞는지와 무엇이 미확인인지’를 보여주면 선택에 도움이 될 것. 소규모 카탈로그의 월 수동 유지가 감당 가능할 것. 아직 실제 반응/장기 운영으로 확인하지 않았다.
- 미검증: 국내 최신 결제 총액/재고, 소음·키감, 국내 유통 옵션·보증, 실제 기기 전반, 시장 수요/재방문/전환, 장기 유지 시간.
- 자동 링크 검사는 Logitech 200, Keychron 429. 초기 공식 페이지 열람과 자동 갱신 가능성을 구분한다.

## 검증
단위 테스트 20개에 모든 2,304 입력 조합 검사 포함. 주요 E2E 20개 통과 후 skip-link 회귀 2개 추가 통과. 1440px/390px 화면, 키보드 탐색, 저장 차단/손상, 빈 결과, 비교 한도, 실제 다운로드 내용, 만료 날짜, 외부 분석 요청 없음 등을 검사했다. 주요 화면 axe serious/critical 0. 타입/빌드/출처 감사/비밀 패턴 검사 통과. 별도 디렉터리 `npm ci`→check→test→build 재현. npm audit 당시 알려진 취약점 0. [QA 상세](QA.md).

앱 내 브라우저 도구 연결은 불가했고 설치된 Edge 테스트와 PNG 시각 검토로 검증했다. 실제 휴대전화, Safari/Firefox, macOS/Linux, 스크린리더 실사용, 배포 환경은 미검증이다.
