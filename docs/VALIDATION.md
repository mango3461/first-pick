# 실제 효용 검증 계획과 현재 증거

**현재 실제 사용자 참가자 수: 0명. 인터뷰/관찰/설문 수집/수요 검증 미수행.** 브라우저 자동 테스트의 입력과 피드백은 소프트웨어 검증용 가상 데이터다. 사용자 반응이나 수요의 증거로 세지 않는다.

## 검증하고 싶은 가설
처음 키보드를 사는 한국어 사용자가 설명과 근거를 통해 필수 조건을 정하고, 구매 전 무엇을 더 확인해야 하는지 설명할 수 있다. 사용 만족도, 재방문, 구매율은 아직 모른다.

## 무예산 첫 관찰 (계획, 아직 실행 안 함)
- 대상: 최근 키보드를 처음 사려는 성인 5명. 지인 자원 참여로 모집하고, 개인정보 없이 P01~P05 식별자 사용. 연락/모집은 실제 대상과 전달 방법이 정해진 뒤 수행한다. 이번 작업에서 메시지를 보내지 않았다.
- 장소: 로컬 실행 화면을 같은 자리에서 보여주거나 승인된 방식으로 화면을 공유한다. 공개 배포 없이도 가능하다. 참여자가 직접 클릭하도록 한다.
- 조건: 15~20분, 무보수 자발적 참여, 중도 중단 가능. 녹음/화면 저장은 별도 동의가 있을 때만 한다. 개인정보·구매 내역을 수집하지 않는다.
- 중립 질문: ‘최근 처음 구매하는 제품을 찾을 때 무엇이 어려웠나요?’, ‘어떤 키보드를 어디에서 쓸 계획인가요?’ 유도 질문이나 추천 제품 구매 강요 금지.

## 관찰 과제 (사전 정의)
1. 첫 화면에서 서비스가 할 수 있는 일/못하는 일을 말해 보기.
2. 개념 글을 읽고 ‘리니어면 무소음인가?’, ‘USB-C 포트가 있으면 유선 입력 가능한가?’ 설명하기.
3. 본인 조건으로 후보를 만들고 2개를 비교하기. 도움 없이 조건 수정하기.
4. 후보를 보여준 이유 2개와 아직 확인해야 할 항목 2개 말하기. 공식 출처 열기.
5. 체크리스트 저장 후, 어떤 정보가 부족해 실제 결정을 못 하는지 자유롭게 말하기.
6. 로컬 피드백 저장/내보내기는 희망할 때만 사용. 자동 전송이 아님을 설명.

## 사전 성공/실패 기준
- 진행 가능: 5명 중 4명 이상이 도움 없이 조건 선택→후보 비교를 마치고, 추천 이유 2개/한계 2개를 정확히 설명.
- 이해 가능: 5명 중 4명 이상이 두 개념 질문을 정확히 설명. ‘추천이므로 가격/소음이 검증되었다’고 오해하는 참가자는 0명이어야 한다.
- 기능 완수 시간은 관찰값으로 기록하며, 이번에는 허위 ‘3분’ 등의 실측 시간을 제품에 표시하지 않는다. 8분 초과 시 어디서 막혔는지 조사.
- 2명 이상이 국내 가격/재고 부재로 후보를 전혀 못 좁히면 화면 확장보다 합법적이고 갱신 가능한 가격 데이터 확보를 우선한다.
- 2명 이상이 작은 카탈로그 때문에 자기 조건에 해당하는 모델이 없으면 데이터 범위를 재설계한다.
- 한 명이라도 근거의 한계를 잘못 이해해 비용/소음을 확신하면 해당 설명을 수정하고 재검증한다.
- 과제 성공은 수요 증명이 아니다. 유료화·구매 전환 추정은 하지 않는다.
