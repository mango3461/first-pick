# 완료 기준 — 구현 전 확정 (2026-11-12 KST)

## 핵심 성립 게이트 (전체 화면 구현 전)
1. 최소 6개 실제품, 2개 제조사의 공개 공식 자료를 직접 확인한다. 모델/옵션, 연결, 배열/숫자패드, OS, 기기 전환, 전원 등 추천에 쓰는 필드는 출처에 연결한다. 불명 값은 null로 남긴다.
2. 작은 추천 엔진으로 필수 조건 충족·불일치·미확인을 구분하고, 모순 조건의 빈 결과 및 소음/가격 미확인을 검증한다.
3. 수동 갱신 절차와 90일 유효기간을 구현한다. 오래된 자료와 미래 날짜/유효하지 않은 출처는 추천에서 제외한다. 자동으로 확인일을 갱신하지 않는다.
게이트 실패 시 화면 개발을 확대하지 않고 실패와 가능한 대안을 보고한다.

## 제품 완료 기준
- 사무/학습용 키보드를 처음 고르는 한국어 사용자가 짧은 개념 설명 → 조건 선택 → 근거가 있는 후보 최대 3개 → 비교/출처/구매 전 체크리스트로 이동할 수 있다.
- 6개 이상 실제 모델과 선택 옵션을 구분하며 각 결과에 이유, 제약, 공식 출처, 확인일을 제공한다. 시장 전체 최선/실측 평가로 표현하지 않는다.
- 가격·재고·소음 실측이 없는 경우 명시한다. 예산 내 구매/도서관 적합을 보증하지 않는다. 엄격한 저소음 요구에는 검증된 후보 없음을 보여준다.
- 조건 수정, 이전 단계, 새로 시작, 빈 결과 복구, 로컬 저장 실패, 잘못된 저장 데이터에서 정상 동작한다.
- 비교와 구매 체크리스트 내보내기가 작동한다. 피드백은 명시적 동작으로 로컬 저장/다운로드만 하며 삭제 가능하다.
- 390px 모바일 및 1440px 데스크톱에서 주요 흐름을 브라우저로 검증한다. 키보드만으로 조작 가능하며 주요 화면 axe serious/critical 위반 0건.
- 추천/데이터 무결성 테스트, 타입 점검, 프로덕션 빌드, E2E가 통과한다. 알려진 미검증 항목을 기록한다.
- npm 잠금 파일, .gitignore, 환경 변수 예시, 설치/실행/검증 문서, 조사/결정/유지 절차, 사용자 검증 계획을 제공한다.
- 실제 사용자 검증은 모집/관찰이 있었을 때만 보고한다. 이번에 실행할 수 없으면 미수행으로 남기고 기술 검증과 구분한다.
- 비밀 점검 및 Git diff 검토 후 커밋한다. 승인된 공개 범위로 GitHub main에 푸시를 시도하고 인증/네트워크 실패를 정확히 기록한다. 배포하지 않는다.

이 기준의 기술 완료와 실제 수요 입증은 다르다. 사용자 검증 결과를 만들거나 합격으로 간주하지 않는다.
