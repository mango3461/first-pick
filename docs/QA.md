## 발견해 수정한 문제
- 처음 axe 검사에서 보조 설명·선택 카드·체크리스트·데이터 숫자의 명암 대비가 4.5:1 미만인 부분 발견 → 색을 진하게 수정, 모바일 핵심 문구 글자 크기 확대, 재검사 통과.
- 화면 제목에 프로그래밍 초점을 옮길 때 불필요한 검은 테두리 표시 → 비조작 요소만 테두리 제거. 실제 링크·버튼·폼의 키보드 초점 표시는 유지.
- 본문 바로가기의 `#main`이 해시 라우터와 충돌할 가능성 발견 → URL을 바꾸지 않고 본문에 초점 이동, 회귀 테스트 추가.
- 저장된 답에 예상 밖 키가 들어가면 결과 렌더링이 깨질 수 있음 → 정확한 답 필드만 허용.
- 공식 텍스트에 ‘전용 동글 사용’만 있다고 구성품 포함을 확정할 수 없어 B1 수신기 포함도 미확인으로 정정. 옵션의 불명 값은 추천에 유리하게 채우지 않음.

## 도구 제한 / 미검증
- 앱 내 브라우저 도구는 `The browser access host is unavailable`을 반환. 이 도구를 통한 사용자 화면 미리보기는 실패했다. 설치된 Edge 기반 자동 테스트와 로컬 PNG 검토로 대체했다.
- Keychron 자동 HTTP 검사 429는 링크가 깨졌다는 증거도, 내용이 바뀌었다는 증거도 아니다. 초기 웹 도구의 공식 페이지 열람으로 사양을 확인했고, 자동 재검증 성공으로 기록하지 않았다.
- macOS/Linux 실행, Firefox/Safari, 실제 iOS/Android 기기, 스크린리더 실사용, 대규모 부하, 공개 배포 환경은 확인하지 않았다.
- 가격·재고·측정 소음·실제 키감·제품 실물·현재 국내 판매 여부는 검증하지 않았다.
- 실제 사용자 참여 0명. 테스트 입력과 피드백은 가상 데이터이며, 실제 수요/만족도/전환 성과를 보고하지 않는다.
